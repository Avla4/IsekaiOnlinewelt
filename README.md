# Isekai Onlinewelt – Windows-Testversion

Downloads und signierte Spielupdates für eingeladene Tester. Ein gemeinsamer Spielserver ist ausschließlich über Tailscale erreichbar.

## Start
IsekaiOnlinewelt-Launcher.exe herunterladen und starten. Tailscale muss verbunden sein und der Spielserver muss für dich im Tailnet freigegeben sein. Dann Spielen wählen. F11: Vollbild. Esc: Optionen. Tab: Tagebuch.

Der Launcher enthält die erste Spielversion, prüft beim Start signierte Updates und bewahrt die vorherige Version. Spielstände und Optionen werden nicht durch Updates ersetzt. Keine GitHub-Tokens im Launcher.

Windows 10/11 x64 und .NET Framework 4.8. Prototyp ohne bezahltes Code-Signaturzertifikat. Keine Produktionseignung oder öffentliche Spielserverfreigabe.
